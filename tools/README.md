# Локальные проверки Draft 2.0

## Smoke-тест

```sh
node tools/smoke.js
```

Скрипт не использует сеть и пакеты npm: он поднимает локальную раздачу
репозитория, запускает установленный Google Chrome в headless-режиме и проходит
онбординг, слепок, граф, пересечения, мир слова, четыре шага развилки и маршрут
«Дополнить» → слепок. Временный профиль Chrome удаляется после прогона.

По умолчанию на macOS используется `/Applications/Google Chrome.app`. Для
другого расположения браузера:

```sh
HAC_CHROME_BIN=/путь/к/chrome node tools/smoke.js
```

Запускай smoke-тест перед каждым коммитом, который меняет `draft/index.html`.
