# Локальные проверки Draft 2.0

## Smoke-тест

```sh
node tools/smoke.js
```

Скрипт не использует сеть и пакеты npm: он поднимает локальную раздачу
репозитория, запускает установленный Google Chrome в headless-режиме и проходит
онбординг, слепок, граф, пересечения, мир слова, четыре шага развилки и маршрут
«Дополнить» → слепок. Временный профиль Chrome удаляется после прогона.

По умолчанию на macOS используется `/Applications/Google Chrome.app`. Для
другого расположения браузера:

```sh
HAC_CHROME_BIN=/путь/к/chrome node tools/smoke.js
```

Запускай smoke-тест перед каждым коммитом, который меняет `draft/index.html`.

## Замер графа из 151 узла

```sh
node tools/smoke.js --graph-151
```

Режим создаёт временный профиль, выбирает все 151 слов словаря и трижды
перезагружает граф в мобильном viewport 390×844. В отчёте выводятся три времени
«от перезагрузки до 151 видимого узла» и среднее. Это диагностический замер,
не пользовательские данные и не часть интерфейса.

## Проверка словаря и развилок

```sh
node tools/validate.js
```

Запускай её при каждом изменении `draft/words_v3.json` или
`draft/dilemmas_v1.json`. Проверка находит отсутствующие ссылки в `neighbors`,
`antonym`, `activates`, `interest`, кандидатах и словах развилок, а также
сверяет JSON-файлы с их встроенными копиями в автономном `draft/index.html`.
