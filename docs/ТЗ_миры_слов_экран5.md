# ТЗ: Экран 5 — Миры слов (Hand & Compass 2.0, черновик MVP)

Источник истины по механикам: docs/10-mechanics-2.0.md, разделы 5.2 (миры слов и петля возвращения), 5.4 (запутанные истории), 5.2.1 (личные пометки), 5.1 (боты-архетипы), 3 (слепок), 8 (главный принцип).

Реализация: внутри draft/index.html (один файл, без сети, localStorage, mobile-first, prefers-reduced-motion). Архивный app/index.html не трогаем. После каждого этапа — commit + push.

---

## 1. Суть экрана

Каждое слово словаря — территория, в которую можно войти.
Экран слова отвечает на вопрос пользователя «а что дальше?»:
здесь живут другие (пока — боты-архетипы), здесь читают и оставляют
анонимные истории, здесь видно, насколько слово общее или редкое.

## 2. Вход в мир слова

- Тап по слову на графе открывает карточку узла (как сейчас) + новая
  кнопка «Войти в мир слова».
- Та же кнопка в карточке слова на экране слепка.
- Кнопка есть у ЛЮБОГО слова (выбранного, предложенного, соседа).

## 3. Структура экрана слова (сверху вниз)

1. **Шапка**: слово крупно, полки слова цветными чипами, кнопка «назад»
   (возврат туда, откуда пришёл — на граф со словом в фокусе).
2. **Статистика** (одна строка, помечена «среди примеров профилей»):
   «Это слово выбрали N из 144 примеров». Если N ≤ 5 — особая строка:
   «Редкое слово: его выбрали всего N из 144».
   Если у слова есть поле interest — строка «Часть большего: <родитель>»
   с тапом на мир родителя.
3. **Кто здесь живёт**: 3–5 ботов-архетипов, у которых это слово в слепке
   (fake_people). У каждого: имя-позывной, метка «пример профиля»,
   одна строка характера. Тап на бота → карта пересечения с ним
   (существующий экран 4 в детальном виде).
4. **Истории** — ядро экрана:
   - Заголовок зависит от полки: для триггеров — «Что случалось»,
     для камней — «Как живут с этим», для ценностей/опор/целей —
     «Истории», для действия/предвидения — «Как это проявляется».
   - 2–3 готовые истории от ботов (см. п.4), у каждой метка
     «пример профиля» и кнопка «Узнаю себя» со счётчиком
     (счётчик = базовое число из данных + тапы пользователя,
     локально). «Узнаю себя» — не лайк: тапнуть можно один раз,
     повторный тап снимает.
   - Кнопка «Написать свою историю»: поле ввода, 1–5 строк, подпись:
     «Анонимно. Сохранится только на этом устройстве, пока продукт
     локальный.» Сохранённая история появляется в списке с меткой
     «твоя история», её можно удалить.
   - Истории пользователя хранятся в localStorage по id слова.
5. **Подвал**: честная строка «Когда подключатся живые люди, здесь
   появятся их истории — анонимно, по их выбору.»

## 4. Истории ботов

Для MVP — встроенный массив в коде: для 12 архетипов × по 2–3 истории,
привязанные к их ключевым словам. История = 1–3 предложения, от первого
лица, житейская, конкретная (не абстрактная мудрость). Примеры тона:
- вспыльчивость: «Сорвался на кассира из-за очереди. Потом полдня
  было стыдно. Теперь выхожу из магазина, когда чувствую, что закипаю.»
- откладывание: «Дедлайн был вчера. Пишу это вместо того, чтобы
  начать. Зато сегодня я это хотя бы заметил.»
Базовый счётчик «узнаю себя» у историй: 3–40 (случайно, фиксировано).

## 5. Чего на экране НЕТ (жёстко)

- Нет ленты, нет сортировки по популярности, нет лайков, нет комментариев.
- Нет оценок слова («плохое/хорошее»).
- Нет выводов о пользователе от системы.
- Нет имён реальных людей — только боты с меткой и «твоя история».

## 6. Технические требования

- Все тексты ≤ 2 строк, кроме самих историй.
- Навигация: мир слова — экран 5; из него можно в пересечение с ботом
  и назад. Хлебные крошки не нужны, только «назад».
- Статистика считается по встроенным fake_people в момент показа.
- При prefers-reduced-motion — без анимаций появления.
- Тёмные полки (камни/триггеры) — приглушённая палитра экрана,
  как сумеречная волна выбора.

## 7. Приёмка

- Вход в мир с графа и со слепка работает, «назад» возвращает в фокус.
- Статистика верна по данным fake_people (проверить 3 слова вручную).
- Редкое слово (N ≤ 5) показывает особую строку.
- Своя история сохраняется, переживает перезагрузку, удаляется.
- «Узнаю себя» тапается один раз, снимается повторным тапом.
- На 375 px нет горизонтального скролла.
- Все боты и их истории помечены «пример профиля».
