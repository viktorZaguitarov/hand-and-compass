# ТЗ: Hand & Compass 2.0 — черновик MVP «Слепок»
## Для передачи в Codex. Версия 1.0

---

## 0. Контекст для разработчика

Это НЕ доработка существующего `app/index.html` (он заморожен как архивный прототип 0.17, ветка `archive/prototype-0.17`). Это новое приложение в отдельной папке `draft/` того же репозитория.

Психологические инварианты честности — в `docs/08-core-mechanics.md` (архивная ветка). Ключевые из них, которые действуют и здесь:

1. Система НЕ ставит диагнозов, НЕ присваивает типов личности, НЕ выдаёт баллы как научное измерение.
2. Всё, что система «поняла» о пользователе, — предложение, которое пользователь может исправить или отвергнуть.
3. Различаем: факты / интерпретация пользователя / гипотезы системы / неизвестное.
4. Никаких внешних вызовов (в т.ч. ИИ-API) в этом черновике. Всё локально, всё детерминировано.

**Технические рамки черновика:**
- Один самодостаточный `draft/index.html` (как и прототип — без сборщиков, без npm).
- Данные словаря и фейковых профилей — из двух JSON-файлов, которые лежат рядом и подключены в проект как JS-объекты (или fetch, если file:// позволяет; иначе инлайн).
- Хранение выбора пользователя — localStorage.
- Mobile-first: первый экран должен быть удобен с телефона (тапы, не ховеры).
- Минимум текста на экранах. Правило: один экран = один вопрос или одно действие. Пояснения — только по тапу «подробнее».
- Все тексты без гендерных окончаний. Пол нигде не спрашивается.

## 1. Данные (уже готовы, лежат рядом)

### 1.1 `words_v2.json` — словарь россыпи
~101 слово. Структура каждого слова:

```json
{
  "id": "spravedlivost",
  "word": "справедливость",
  "shelves": ["values"],
  "neighbors": ["chestnost", "granicy", "dobrota"],
  "antonym": "nespravedlivost",
  "activates": ["vspylchivost", "zhestokost"]   // только у триггеров
}
```

Семь полок (shelves):
| id | Название | Смысл |
|---|---|---|
| values | 💎 Ценности | что по-настоящему важно |
| goals | 🧭 Цели | куда хочу прийти / кем стать |
| action | ✋ Действие | как двигаюсь |
| foresight | 🔭 Предвидение | как просчитываю и мечтаю |
| stones | 🌑 Камни | что во мне мешает |
| supports | 🌿 Опоры | что меня питает |
| triggers | ⚡ Триггеры | что снаружи меня выбивает |

Важно: `shelves` у слова — это **набор граней, а не папка**. Слово может светиться на нескольких полках сразу (например, «энергия» = values + action).

Типы связей в графе:
- `neighbors` — смежные слова (цепочки «что ещё рядом»);
- `antonym` — теневая пара («а вот тень твоего слова»);
- `activates` — у триггеров: какие камни они будят (триггер «крики» → камень «вспыльчивость»).

### 1.2 `fake_people_v1.json` — 144 синтетических профиля
12 архетипов × 12 штук. У каждого: id, name (нейтральный псевдоним вида «Пик-64»), archetype, words (массив id слов из словаря). У фейков все теги открытые.

## 2. Экраны и механики (MVP)

### Экран 1. Россыпь слов (вход)
- Поле из всех слов словаря, перемешанных, в виде тапаемых «жетонов».
- НЕ показывать, к какой полке относится слово, до выбора — выбор должен быть чистым, «что откликается».
- Тап по слову = выбрать (визуально подсвечивается). Повторный тап = снять.
- Поле ввода «своё слово»: пользователь может добавить любое (аниме, красный цвет, запах дерева). В черновике своё слово просто добавляется в слепок без полки (полка «✨ Своё»), с пометкой «полка определится позже».
- Рекомендация на экране (одна строка): «Выбери 8–15 слов, которые откликаются».
- Кнопка «Готово» активна от 5 выбранных слов.

### Экран 2. Слепок (результат)
- Выбранные слова раскладываются по семи полкам — семь зон с названиями и эмодзи.
- Каждое слово показано в своих полках; мультиполочные слова визуально выделены (например, двойная рамка): «это слово живёт сразу в двух местах».
- Под каждой полкой — одна честная строка-сводка БЕЗ диагнозов: сколько слов выбрано, какие. Пример: «🌑 Камни: ты сам отметил 4 — это много говорит о честности, не о поломке».
- Никаких процентов личности, типов и «вы — такой-то».
- Кнопки: «Править выбор» (назад), «Смотреть граф», «С кем я пересекаюсь».

### Экран 3. Граф (обсидиан-режим)
- Визуализация выбранных слов как графа: узлы = слова, рёбра = neighbors из словаря (только между выбранными), цвет узла = основная полка, пунктир = связь к невыбранному соседу.
- Тап по узлу:
  - подсвечивает его цепочку (соседи, соседи соседей);
  - внизу карточка слова: полки, соседи (тапабельные), теневая пара («тень: откладывание — узнаёшь?» с кнопкой «и это тоже про меня» — добавляет тень в слепок!), для триггеров — какие камни будит.
- Тап по невыбранному соседу в цепочке = «добавить и его?» — так слепок густеет через блуждание.
- Мини-разбор (по желанию): в карточке слова кнопка «разобрать в себе» → один экран, один вопрос («Когда в последний раз это было важно? Одной фразой») → ответ сохраняется к слову как заметка-подтверждение.

### Экран 4. Пересечения (фейковые люди)
- Ползунок: «похожесть» от 0% до 100%.
- При каждом значении — список из 3–5 фейковых профилей, ближайших к этому уровню совпадения.
- Совпадение считается взвешенно: values ×3, stones ×2, goals ×2, foresight ×1.5, action ×1.5, triggers ×1, supports ×0.5 (Jaccard по словам с весами полок).
- Тап по профилю → карта пересечения: три блока:
  1. «Общее поле» — пересекающиеся слова по полкам;
  2. «Дополнение» — что есть у него и нет у тебя (и наоборот), сгруппировано по полкам;
  3. «Точки трения» — где его слова попадают в твои триггеры/камни и наоборот (например: «его напористость ↔ твой триггер "давление"»).
- Честная подпись: «Совпадение не значит совместимость. Это карта, а не приговор».

### Экран 5. Приватность (заготовка)
- В настройках слепка: у каждого слова три уровня — 🔒 только мне / 👁 видно при совпадении / 🌍 открыто.
- По умолчанию: камни и триггеры — 🔒, остальное — 👁.
- В черновике уровни только сохраняются и визуально отображаются; реальной публикации нет.

## 3. Нефункциональные требования

- **Визуальная привлекательность — требование №1.** Наследуем дух прототипа 0.17 (бумага, лесные тона, золото, мягкие тени — см. `:root` в `app/index.html`), но плотнее и современнее. Граф — главный экран, должен быть красивым: плавные кривые, лёгкая физика/анимация, без резких движений (учитывать prefers-reduced-motion).
- Адаптивность: полностью играбельно с телефона.
- Никаких сетевых запросов, трекеров, внешних шрифтов.
- Доступность: ARIA-подписи, контраст, DOM через textContent.

---

## 4. Что НЕ входит в этот черновик

- Аккаунты, сервер, БД, реальные пользователи.
- ИИ внутри продукта (классификация своих слов, гипотезы) — этап 2.
- Дороги/Компас/Дракон из прототипа — этап 3 (глубина поверх слепка).
- Реальный матчинг между живыми людьми.

---

## 5. Критерий готовности черновика

Автор открывает `draft/index.html` с телефона и может: выбрать слова → увидеть слепок по полкам → поблуждать по графу с цепочками и тенями → добавить слово-тень → разобрать одно слово одной фразой → двинуть ползунок и увидеть 3 карты пересечения с фейками → выставить приватность. Всё — без чтения текстов длиннее двух строк.

## 6. Юридическая заметка (на будущее, для этапа с реальными пользователями)

Слепки ценностей/камней — персональные данные (152-ФЗ), камни и триггеры пограничны со специальными категориями. Целевой хостинг — серверы на территории РФ (Яндекс.Облако), регистрация в Роскомнадзоре как оператора ПД до публичного запуска. В локальном черновике ПД нет — данные не покидают браузер.
